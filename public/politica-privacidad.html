Política de privacidad de Tiendita San Isidro

Última actualización: 10 de octubre de 2026

Esta política explica qué información trata el sistema de gestión Tiendita San Isidro, para qué se utiliza y cómo puedes comunicarte con quien lo administra.

Información que se trata

  • Cuenta: nombre de usuario, correo electrónico y datos técnicos de autenticación. La contraseña se almacena como un hash con sal; no se guarda como texto legible.
  • Gestión de la tienda: categorías, nombres de productos, precios, existencias, fechas y totales de ventas, y los productos y cantidades de cada venta que se registran en el sistema. El sistema no solicita datos de compradores para asociarlos a las ventas.
  • Seguridad y sesión: se usa una cookie de sesión para mantener el acceso. La aplicación puede tratar temporalmente datos técnicos de solicitudes, como la dirección IP, para limitar intentos de acceso. Los proveedores de alojamiento pueden generar registros técnicos de sus servicios.

Uso de la información

La información se utiliza para autenticar cuentas, operar las funciones de inventario y ventas, proteger el servicio y enviar mensajes de verificación de correo o restablecimiento de contraseña cuando se solicitan.

Para esos mensajes, la aplicación usa la API de Gmail con permiso para enviar correos desde la cuenta remitente configurada. No usa ese permiso para leer la bandeja de entrada. Los enlaces de verificación y recuperación son de un solo uso y vencen después de una hora; sus tokens se almacenan como hashes.

Proveedores de servicio

La aplicación utiliza Vercel para alojar y desplegar el sitio y la API, Neon para alojar la base de datos PostgreSQL, y Google Gmail API para enviar los mensajes descritos arriba. Estos proveedores pueden tratar información técnica y datos necesarios para prestar sus servicios, conforme a sus propias políticas:

  • Política de privacidad de Vercel
  • Política de privacidad de Neon
  • Política de privacidad de Google

La aplicación no vende información personal ni la utiliza para publicidad.

Conservación y eliminación

La información de cuenta y los registros de inventario y ventas se conservan mientras permanezcan en la base de datos del servicio. Los tokens temporales vencen después de una hora y las sesiones expiran después de siete días. Actualmente, la aplicación no ofrece una opción automática para eliminar una cuenta. Para solicitar acceso, corrección o eliminación de información, escribe al contacto indicado abajo; la solicitud se revisará y se atenderá cuando sea posible y conforme a las obligaciones aplicables.

Seguridad

Se aplican medidas técnicas como conexiones HTTPS en producción, contraseñas protegidas mediante hash y cookies de sesión inaccesibles a JavaScript. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

Privacidad de menores

Este sistema de gestión está dirigido a quienes administran una tienda y no está diseñado para que menores de edad creen cuentas.

Cambios a esta política

Esta política puede actualizarse si cambian las funciones o el tratamiento de información. La fecha de actualización al inicio indicará la versión vigente.
